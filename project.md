Aims of this project:

* Provide easy access to temperatures in different rooms in form of graphs available from a site hosted in local
  network.
* Learn about home automation systems.
* Have fun programming this.
* Optimize room temperatures.

I have a house:

* There are many heaters hung on the walls.
* There is an atmospheric boiler supplying hot water for heaters.
* The boiler is controller by a thermostat with radio control. The thermostat is mobile.

For the starter I want to monitor temperature in 4 rooms, code the app managing and displaying the data.

Non-functional requirements:

* The sensors need to be battery powered and work long on the batteries.
* Ideally the sensors need to have a screen showing the temperature.
* The sensors need to be relatively cheap.
* All of this needs to be safe - probably completely closed from outside Internet.

Ideas for future:

* Get the boiler turn on/off times.
* Host the app somewhere on AWS so that I can see the temperatures while outside.
* Control the boiler inteligently.
* MCP with measurements to analyse data with AI.
